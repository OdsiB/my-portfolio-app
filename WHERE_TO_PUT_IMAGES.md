## ⚡ How to Add an Image:

1. In the file explorer on the left, navigate to the folder (e.g. `public/images/selected-work/`).
2. Drag and drop your image into the folder.
3. Rename the file to match the name in the table above (e.g. `selected-01.jpg`).
4. The portfolio will automatically display your uploaded image!
